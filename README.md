# Responsive Pricing Table

A responsive pricing table created using HTML5 and CSS3 as part of my Web Development Internship Day 12 task.

## Project Description

This project displays three pricing plans with their prices, features, and call-to-action buttons. The Pro plan is highlighted as the Popular plan. The layout is responsive and automatically stacks the pricing cards on smaller screens.

## Features

- Three pricing plans
- Basic, Pro and Premium plans
- Highlighted Popular plan
- Feature lists for each plan
- Monthly pricing
- Call-to-action buttons
- Button hover effects
- Card hover animations
- Responsive layout
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
